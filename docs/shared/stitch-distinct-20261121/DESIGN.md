# نوادر الإبل — الأسلوب المتمايز (MOBILE-GUI-DISTINCT-20261121)

لغة تصميم جديدة بدل «العصري المختصر»، بنفس الألوان والشعارين وقواعد المنتج. المرجع الوحيد للقيم هو `ui.css` (آخر قسم فيه) و`build_previews.py`.

## ثابت دون تغيير
- الألوان: فاتح (خلفية #FFFFFF، نص #2D241B، ذهبي #A77434، خط #E8E2D8، رمادي دافئ #F5F1EA) وداكن (#111B1C، #202D2D، ذهبي #E4BC7B). ألوان الحالات والـtints كما هي.
- الشعاران الأصليان، RTL، أرقام الجوال والرمز LTR، 61 شاشة بالوضعين، وكل قواعد المنتج (مزاد حضوري بلا مزايدة أو دفع، المراجعة قبل النشر، موافقات غير مفعّلة مسبقًا…).

## شاشة البداية A00 (MOBILE-SPLASH-20261121)
- المصدر: «شاشة تحميل نوادر الإبل» (Nawader_Loading.html): شعار SVG يمشي مع كثبان وعبارة «جارٍ التحميل». الملفات: `splash.css` و`splash.js` و`splash-emblem.svg.html` و`splash-dunes.svg.html`، ويدمجها `build_previews.py` في A00 فقط (A00 = الرئيسية B01 + طبقة البداية).
- التوقيت: عرض ثابت 1000ms، ثم انتقال 720ms: الشعار ينكمش ويهبط على صورة شعار الترويسة (يُحسب الموضع والحجم من مستطيل الصورة الفعلي)، يتلاشى الغطاء والكثبان، تظهر الرئيسية، ثم يُستبدل الـSVG بصورة الترويسة.
- الوضعان الفاتح والداكن: لون الخلفية ولون تعبئة الأرجل يتبعان `--bg`. «تقليل الحركة»: شعار ثابت ثم تلاشٍ قصير دون مشي أو انتقال مكاني.

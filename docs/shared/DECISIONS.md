## TEAM-DEC-001 — فصل مسؤولية الإدارة والجوال

- التاريخ: 2026-11-15.
- الحالة: معتمد بتوجيه المستخدم في المحادثة.
- القرار: مطور للإدارة وآخر للجوال، ويحدد كل برومبت جانب الذكاء الاصطناعي ويمنع تدخله في الجانب الآخر. تحفظ متابعة التقدم وأهم القرارات في Markdown مشتركة داخل Workspace.
- التطبيق: تعليمات الجذر والمجلدات وقوالب `PROMPTS.md` وسجلات هذه الحزمة.
- الأثر: الاحتياجات العابرة للجانبين تسجل وتُسند، ولا تنفذ بتوسيع ضمني لنطاق المهمة.

## TEAM-DEC-002 — إسناد الأجزاء المشتركة والموقع العام

- التاريخ: 2026-11-15.
- الحالة: ترتيب تنسيقي مؤقت؛ المالك الدائم غير محدد.
- السياق: المتطلبات تشمل موقعًا عامًا وSupabase وعقود بيانات مشتركة، بينما توزيع المستخدم يحدد الإدارة والجوال فقط.
- الإجراء الحالي: لا حذف لهذه المتطلبات ولا إسناد تلقائي لها. يحدد لكل مهمة مشتركة منفذ واحد من المطورين ومسارات واضحة. يحتاج الموقع العام إسنادًا صريحًا.
- الحسم المطلوب: تحديد المسؤولية المستمرة لهذه الأجزاء عند التخطيط لتنفيذها؛ انظر `INT-001`.

## TEAM-DEC-003 — تكييف ملف تصميم الجوال مع البيئة المتاحة

- التاريخ والجانب والكاتب: 2026-11-15 — Asia/Riyadh؛ MOBILE / Codex.
- الحالة: قرار تنفيذ للتصميم ضمن تكليف المستخدم بتنفيذ الخطة؛ لا يغير متطلبات المنتج أو ملكية الشيفرة.
- المصدر: اختيار المستخدم سوقًا عصريًا بلمسة تراثية وملفًا جديدًا ومراحل حسب الاكتمال، ثم طلب تنفيذ الخطة؛ نتائج اكتشاف الخطوط وحدود خطة Starter في Figma.
- القرار: Noto Sans Arabic بديلًا عن IBM Plex Sans Arabic غير المتاح؛ 3 صفحات تجمع أقسام الخطة بدل 8 صفحات؛ مجموعتا ألوان Light وDark أحاديتا الوضع بسبب حدود الحساب. قيم الهوية الأصلية محفوظة كمتغيرات؛ الإضافتان #72665A و#8A5C25 من الخطة مخصصتان لوضوح النصوص والإجراءات في الوضع الفاتح.
- الأثر: للجوال فقط. لا إسناد لعمل الويب أو الإدارة أو الخلفية، ولا عقد API أو قرار منتج جديد. أصول الشعار محفوظة دون إعادة تصميمها؛ الصور والخرائط التجريبية موسومة في سجل التسليم.
- التحقق: إنشاء الملف والمتغيرات والمكونات والشاشات؛ مراجعة بصرية للمكونات والرئيسية فقط حتى بلوغ حصة MCP. يبقى التسليم الكامل قيد المراجعة وفق سجل التقدم.

## TEAM-DEC-004 — هوية وتسليم تصميم Stitch للجوال

- التاريخ والجانب والكاتب: 2026-11-16، 15:02 — Asia/Riyadh؛ MOBILE / Codex؛ المهمة MOBILE-GUI-STITCH-20261116.
- الحالة: قرار تنفيذ ضمن طلب المستخدم المباشر إنشاء جميع واجهات الجوال باستخدام Google Stitch ودليل الألوان والشعارين المرفقين، مع تبسيط الاستخدام.
- القرار: مشروع Stitch مستقل للجوال، بألوان الدليل الأصلية وخط Noto Sans Arabic وشعاري المصدر دون إعادة رسم. يستخدم النص البني الكبير الغامق على الذهبي الفاتح، وتسميات ظاهرة للأفعال وخطوات قصيرة. المعرض يجمع 74 شاشة/حالة بالمظهرين، مع فصل عدد الشاشات الأصلية في Stitch عن النسخ الداكنة المشتقة محليًا.
- الأثر: يخص حزمة Stitch الحالية فقط؛ لا يستبدل قرار Figma السابق أو يغير المنتج أو المسؤوليات أو عقود الخدمات. المزاد حضوري والتوثيق اختياري ولا يفترض مزودًا غير معتمد؛ السياسات لا تستحدث نصًا قانونيًا معتمدًا.
- التحقق: حفظ المشروع ونجاح تحديث 79 شاشة أصلية، 148 معاينة محلية، وفحوص العرض والعينة الموثقة في تقرير التسليم. الاعتماد مع المستخدمين والفحص الكامل للإتاحة لم ينفذا.

## TEAM-DEC-005 — إعادة تصميم الجوال بأسلوب عصري مختصر

- التاريخ والجانب والكاتب: 2026-11-17، 10:22 — Asia/Riyadh؛ MOBILE / Codex؛ MOBILE-GUI-MODERN-20261116.
- الحالة والمصدر: قرار تنفيذ ضمن توجيه المستخدم الصريح إعادة تصميم جميع الواجهات في مشروع آخر، بخط أصغر وتفاصيل أساسية فقط.
- القرار: مشروع Stitch مستقل يحتفظ بالهوية والشعارين، ويستخدم IBM Plex Sans Arabic بحجم أساسي 14px وعناوين 20–22px وأزرار رئيسية عادة 44px، مع شبكة صور من عمودين وتفاصيل ثانوية قابلة للفتح. أضيف #76695C للنص الثانوي الصغير مع حفظ قيمة الدليل #817568 في التوثيق؛ لا تغيير لمتطلبات الموافقات أو أهلية الحساب والإعلانات.
- الأثر: حزمة الجوال الجديدة فقط؛ المشروع السابق وقرار تسليمه محفوظان. لا تغيير ملكية أو متطلبات منتج أو عقود أو شيفرة ADMIN/الويب/الخلفية. المظهر الداكن مشتق محليًا، مع فصل عدد إطارات Stitch عن المعاينات.
- التحقق: 74 شاشة ظاهرة في Stitch و148 معاينة محلية؛ فحوص العرض والتفاعل والمراجعة المحدودة موثقة في [تقرير التسليم](./MOBILE-GUI-MODERN-20261116.md). يبقى اختبار الاستخدام والإتاحة الكامل وتنفيذ التطبيق مهام لاحقة.

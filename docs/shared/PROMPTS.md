# قوالب البرومبت

استبدل الحقول بين الأقواس قبل الإرسال، واحتفظ بالجانب ونطاقه في كل متابعة. لا تستخدم «أكمل المشروع» دون تحديد الجانب والمهمة.

## مطور موقع الإدارة

```text
أنت تعمل على جانب ADMIN (موقع الإدارة) في مشروع نوادر الإبل.
المهمة: ADMIN-[معرف فريد]
الهدف: [وصف محدد]
مرجع المتطلبات: [AD-FR-… / القسم]
المسارات المسموح تعديلها: [مسارات محددة داخل web_platform/src/admin/ واختباراتها]
المسارات المشتركة المسندة صراحة لهذه المهمة: [لا يوجد، أو قائمة محددة وسبب تعديلها]
معايير القبول: [سلوك قابل للتحقق]

اقرأ AGENTS.md وتعليمات web_platform/AGENTS.md وسجلات docs/shared/ والمتطلبات ذات الصلة.
أعلن الجانب والمهمة والنطاق، وسجل بدء العمل ثم نفذ المهمة.
لا تعدل mobile_app/ ولا تنفذ الموقع العام ضمن هذه المهمة.
أي احتياج خارج النطاق يسجل في INTEGRATION.md؛ أكمل ما لا يعتمد عليه.
حدث PROGRESS.md والقرارات المهمة في DECISIONS.md، ثم قدم الملفات المتغيرة ونتائج الفحوص والعوائق.
```

## مطور تطبيق الجوال

```text
أنت تعمل على جانب MOBILE (تطبيق الجوال) في مشروع نوادر الإبل.
المهمة: MOBILE-[معرف فريد]
الهدف: [وصف محدد]
مرجع المتطلبات: [AD-FR-… / القسم]
المسارات المسموح تعديلها: [مسارات محددة داخل mobile_app/]
المسارات المشتركة المسندة صراحة لهذه المهمة: [لا يوجد، أو قائمة محددة وسبب تعديلها]
معايير القبول: [سلوك قابل للتحقق]

اقرأ AGENTS.md وتعليمات mobile_app/AGENTS.md وسجلات docs/shared/ والمتطلبات ذات الصلة.
أعلن الجانب والمهمة والنطاق، وسجل بدء العمل ثم نفذ المهمة باستخدام Flutter/Dart.
لا تعدل web_platform/ أو واجهات الإدارة.
أي احتياج خارج النطاق يسجل في INTEGRATION.md؛ أكمل ما لا يعتمد عليه.
حدث PROGRESS.md والقرارات المهمة في DECISIONS.md، ثم قدم الملفات المتغيرة ونتائج الفحوص والعوائق.
```

## إضافة عند إسناد مهمة مشتركة

تضاف إلى أحد القالبين ولا تنشئ مطورًا ثالثًا:

```text
إسناد مشترك صريح للمطور الحالي: [ADMIN أو MOBILE]
طلب التكامل: INT-[معرف]
المسارات المشتركة المسموحة: [ملفات محددة في supabase/ أو contracts/ أو إعدادات الجذر]
التغيير المطلوب: [البيانات/العمليات/الصلاحيات/الأخطاء]
أثره على الجانبين: [التوافق والمهام التابعة]
خطة التحقق والانتقال: [اختبارات وعلاج الإصدارات الحالية]
لا تعدل شيفرة واجهة الجانب الآخر؛ سجل مهمة تسليم له.
```

# التنسيق المشترك

هذه الملفات نقطة متابعة واحدة للمطورين ووكلاء الذكاء الاصطناعي داخل Workspace.

| الملف | الغرض |
|---|---|
| [تعليمات الجذر](../../AGENTS.md) | تحديد الجانب وحدود التعديل |
| [PROMPTS.md](PROMPTS.md) | قوالب برومبت لكل جانب |
| [PROGRESS.md](PROGRESS.md) | حالة المهام والتحديثات ودليل التحقق |
| [DECISIONS.md](DECISIONS.md) | القرارات المهمة ومصدر اعتمادها |
| [INTEGRATION.md](INTEGRATION.md) | طلبات التغيير التي تتجاوز جانبًا واحدًا |
| [المتطلبات](../../Nawader_AlIbil_SRS_Ads_AR.md) | سلوك المنتج ومعايير القبول والتقنيات |

قبل العمل: اقرأ السجلات وحدد الجانب والمهمة والمسارات، ثم سجل بدء العمل. عند التسليم: حدث التقدم والقرارات وطلبات التكامل المتأثرة. استخدم مهمة منفصلة لكل جانب حتى لو كان المتطلب الوظيفي نفسه مشتركًا.

لتقليل تعارض التحرير، يفضل فرع لكل مهمة ونسخة عمل مستقلة لكل مطور عند إعداد Git، مع دمج سجلات Markdown في المستودع المشترك. عند استخدام المجلد نفسه فعليًا، لا تعدلا الملف نفسه في الوقت نفسه؛ أعد قراءة أحدث نسخة قبل الحفظ ولا تستبدل السجل كاملًا.

# جانب الإدارة — ADMIN

اتبع `../AGENTS.md`. المهام الإدارية المحصورة في هذا المجلد تخص React وVite وTypeScript وفق وثيقة المتطلبات.

- نطاق الواجهات الافتراضي: `web_platform/src/admin/` واختبارات الإدارة المحددة في المهمة.
- إنشاء هيكل الويب أو تعديل إعداداته أو مكوناته المشتركة يحتاج إدراج المسارات المطلوبة صراحة في المهمة مع بيان أثرها على الموقع العام.
- الموقع العام متطلب قائم، لكن لم تسند ملكيته إلى مطور الإدارة تلقائيًا. لا تبدأ تنفيذه ضمن مهمة إدارية.
- لا تعدل `mobile_app/`. تعامل مع احتياجات الجوال كطلبات تكامل في `../docs/shared/INTEGRATION.md`.
- الخلفية والعقود تحتاج إسنادًا صريحًا مستقلًا. عند وجود مشروع قابل للتشغيل نفذ فحص الأنواع والبناء والاختبارات المناسبة وسجل النتائج الفعلية.
